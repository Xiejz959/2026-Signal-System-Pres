# Rehearsal Checklist 1.0

## 上台前必须确认

- `Voice_Noise_Presentation_1.1.pptx` 可以正常打开
- 音频播放按钮能正常工作
- 备用音频文件存在于本地
- 讲解电脑的音量测试正常
- 每位成员知道自己讲哪几页

## Demo 部分

- clean / noisy / filtered 的顺序已经固定
- 三段音频都来自同一段样本
- 音频长度控制在 30-60 秒总时长内
- waveform 和 spectrogram 对应的是同一段音频
- 演示时不会切太多窗口

## 内容部分

- 每页只有一个主要结论
- 不会照着页面逐字念
- `3200 Hz` 的选择理由能在 30 秒内说清楚
- 知道为什么 `3600 Hz` 没被选为主 demo
- 知道为什么这个项目属于 Signals and Systems

## Q&A 部分

- 知道为什么采用仿真而不是真实录音
- 知道为什么选高频 hiss
- 知道为什么选 low-pass
- 知道方法的局限
- 知道如果噪声更复杂该怎么回答
