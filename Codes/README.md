This folder stores all supporting code files used in the project.

It may include Python scripts, MATLAB programs, small simulations, plotting tools, and other code written for analysis, demonstrations, or presentation materials. In short, if it runs and helps the project, it belongs here. 

## Usage

The recommended conda environment file for this folder is:

- `environment_voice.yml`

To set up the environment quickly, run:

```bash
bash setup_env.sh
conda activate voice
```

Current utility files in this folder include:

- `simulate_voice_noise_demo.py`: generates demo audio samples
- `environment_voice.yml`: shared conda environment definition
- `setup_env.sh`: quick setup script for the shared environment
