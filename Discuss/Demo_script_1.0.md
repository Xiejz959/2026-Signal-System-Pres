# Demo 讲解稿 1.0

## Demo 目标

这一段 demo 的目标很简单：让听众在一分钟之内同时感受到三件事：

- 原始语音是什么样
- 高频 hiss 噪声带来了什么问题
- 滤波系统做出了什么改善

## 推荐顺序

### 开场一句话

我们模拟了一段公共广播风格的语音，并人为加入高频 hiss 噪声，来构造一个可分析、可展示的语音降噪场景。

### 第一步：播放 clean voice

这一段是原始语音信号，它代表系统中理想情况下的广播语音。

### 第二步：播放 noisy voice

这一段加入了高频 hiss 噪声。可以注意听一下，语音仍然可懂，但高频底噪已经开始明显影响清晰度。

### 第三步：播放 filtered voice

这一段是经过 low-pass filter 处理后的结果。可以听到高频噪声被压低了，语音也更干净一些，但高频细节会比原始语音稍微少一点。

### 第四步：切到图像

接下来再看图。  
在 waveform 里，可以看到处理前后整体信号形态的变化。  
在 spectrogram 里，可以更清楚看到高频区域在滤波后被削弱，这也是为什么听感上会更干净。

## 收束句

这个 demo 说明，基础 low-pass filter 在这个高频 hiss 场景下是有效的，但它本质上是在“抑制噪声”和“保留语音细节”之间做平衡。
