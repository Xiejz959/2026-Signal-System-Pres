# 参数选择说明 1.0

## 当前默认参数

目前主 demo 默认采用的滤波器配置是：

- 四阶 Butterworth low-pass filter
- cutoff frequency = `3200 Hz`

同时保留 `3600 Hz` 作为补充比较版本，用来说明不同参数下“噪声压制”和“语音保留”之间的取舍。

## 为什么不是直接选输出 SNR 最高的版本

从第一轮实验数据来看，`3600 Hz` 的输出 SNR 更高，说明它在数值指标上表现更强。但课堂展示不能只看一个指标，因为我们最终要展示的是“语音降噪系统”，而不是单纯做一个数值优化问题。

如果 cutoff 设得更高，虽然保留的语音细节更多，但高频噪声也会残留更多。对于课堂 demo 来说，这会影响听感上的“问题是否被明显改善”。

## 为什么选 3200 Hz

最后把 `3200 Hz` 作为主 demo 参数，主要基于下面三点考虑：

第一，它在第一轮比较中已经给出不错的 SNR 改善，同时和 clean voice 的相关性也保持得很好。  
第二，它对高频噪声的压制更明显，前后对比更适合课堂展示。  
第三，它在听感上比 `2800 Hz` 更自然，又比 `3600 Hz` 更能体现“滤波系统确实起作用了”。

换句话说，`3200 Hz` 不是“唯一最优”的数学答案，而是当前最适合作为 presentation 主 demo 的工程选择。

## 怎么向老师或同学解释这组参数

可以用下面这句作为统一说法：

> We chose 3200 Hz as the main cutoff because it gives a better balance between suppressing high-frequency hiss and preserving speech clarity.

中文表达可以是：

> 我们最终选择 3200 Hz 作为主 cutoff，是因为它在高频噪声抑制和语音清晰度保留之间表现得更平衡。

## 为什么不直接用 2800 Hz

`2800 Hz` 的问题在于压得太狠，虽然高频噪声会更少，但语音的高频细节也会被削弱得更明显，听起来容易发闷。

## 为什么不直接用 3600 Hz

`3600 Hz` 保留的语音细节更多，但高频噪声残留也会更多。在实际课堂展示里，这会让前后差异变得没那么明显，不如 `3200 Hz` 稳定。

## 当前结论

所以这一步的结论不是“3200 Hz 是理论上绝对最优”，而是：

- `2800 Hz`：噪声压制更强，但语音更闷
- `3600 Hz`：语音更自然，但噪声残留更多
- `3200 Hz`：最适合当前项目的主 demo 展示
